# Amelia & Lorenzo · Invitación interactiva

Sitio estático listo para GitHub Pages. No requiere npm ni compilación.

## Publicar

1. Crea un repositorio en GitHub.
2. Sube **el contenido de esta carpeta** a la raíz del repositorio: `index.html`, `assets/`, `.nojekyll` y este `README.md`.
3. En **Settings → Pages → Build and deployment**, elige **Deploy from a branch** y selecciona la rama `main` y la carpeta `/(root)`. Guarda.
4. Cuando GitHub termine de publicar, abre la URL indicada en Pages.

No cambies la ubicación de `assets/` respecto de `index.html`. El sobre, los videos, la tarjeta para raspar, el mapa y las lámparas funcionan sin servidor. **La confirmación de asistencia solo simula el envío:** para recibir respuestas habrá que conectar un formulario o servicio después.

Fecha de la invitación: 28 de noviembre de 2027. Los nombres, textos y enlaces se editan en `index.html`.
